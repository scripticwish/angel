# Angel Team — сайт школы фигурного катания

Многостраничный премиальный сайт школы фигурного катания **Angel Team** (Нижний Новгород).
Эстетика — «Ледяная элегантность» × «Спортивная дисциплина».

## Быстрый старт

Сайт собран на **чистых HTML5 + CSS + ванильном JS** — без сборки и внешних зависимостей,
поэтому открывается сразу из папки (двойной клик по `index.html`) или через любой статический сервер.

```bash
# вариант 1 — просто откройте index.html в браузере
# вариант 2 — локальный сервер (рекомендуется)
cd angel-team
python -m http.server 8080
# → http://localhost:8080
```

> Единственная внешняя зависимость — шрифты Google Fonts. Без интернета сайт
> корректно деградирует на системные шрифты (fallback уже прописан).

## Дизайн-система (кратко)

| Токен | Значение | Роль |
| --- | --- | --- |
| `--ink-900` | `#0A0F1F` | основной фон |
| `--ink-700` | `#1A2A4A` | градиент фона |
| `--plat` | `#C7D2DC` | платина / серебро |
| `--ice` | `#F5F8FA` | холодный белый |
| `--cyan` | `#00E5FF` | акцент (свечение льда) |
| `--lavender` | `#A8B8E8` | редкий доп. акцент |

- **Заголовки** — Unbounded (верхний регистр, широкий трекинг)
- **Текст** — Manrope, 16–18px, line-height 1.6
- **Цитаты** — Playfair Display Italic
- Эффекты: glassmorphism, parallax-градиенты, снег на canvas, fade-in-up (Intersection Observer)

## Уникальные интерактивные элементы

1. **Jump Lab** — интерактивная схема прыжков (тулуп → аксель) с анимированным вращением
   фигуриста и шкалой сложности. На главной и в секции «Академия техники».
2. **Program Finder** — калькулятор подбора программы по возрасту, опыту и цели (10 секунд до ответа).
3. **Смена темы** — кнопка солнце/луна в шапке переключает тёмную и светлую тему (выбор сохраняется).

## Админ-панель (`admin.html`)

Вход по паролю (SHA-256). Доступ только владельцу и модераторам. Позволяет добавлять,
редактировать и удалять **занятия расписания** и **записи блога**, а также сбрасывать к
демо-данным. Ссылка «Вход для персонала» — в подвале каждой страницы.

- Данные хранятся в `localStorage` браузера (ключи `at_schedule`, `at_blog`), публичные
  страницы (`blog.html`, `schedule.html`) читают их и рендерят автоматически.
- ⚠️ Для настоящего сайта с несколькими посетителями и модераторами перенесите это на
  backend (PHP/Node + БД): `localStorage` работает в рамках одного браузера.

## Что заменить перед продакшеном

- **Фото/видео** — сейчас визуалы отрисованы SVG/CSS. Подставьте реальные кинематографичные кадры:
  `assets/img/hero.mp4` (фон hero), фото тренеров (в `trainer.html`/`index.html` заменяются
  `<svg>` в карточках), фото галереи в `about.html`.
- **Контакты** — телефон, email, ссылки Telegram/VK, реквизиты (сейчас заглушки).
- **Домен** — `angelteam-nn.ru` в canonical/OG (замените на реальный).
- **Формы** — сейчас валидация клиентская + имитация отправки. Подключите реальный backend
  (или Telegram-бота / CRM) в обработчике `form[data-validate]` в `main.js`.

## Доступность и SEO

- Семантика HTML5, корректная иерархия заголовков, skip-link, aria-атрибуты, фокус-состояния.
- Контраст текста на тёмном фоне соответствует WCAG AA.
- `prefers-reduced-motion` отключает анимации.
- Мета-теги, Open Graph, микроразметка Schema.org (SportsActivityLocation, LocalBusiness).
- Mobile-first: контрольные точки 360 / 768 / 1440.
